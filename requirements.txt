# Install order. Do not start with `pip install -r`: torch is a transitive
# dependency of accelerate and deepspeed, so pip would resolve whichever build
# the default index happens to offer instead of the one you want.
#
#   1) torch + torchvision FIRST and alone, from the index matching your driver:
#        pip install --index-url https://download.pytorch.org/whl/cu128 \
#            torch==2.8.0 torchvision==0.23.0
#      The CUDA runtime arrives inside the wheels; a system CUDA toolkit is only
#      needed to compile (flash-attn, and DeepSpeed's CPU-Adam for the offload
#      configs). On a CPU-only host use the CPU index explicitly --
#      https://download.pytorch.org/whl/cpu -- because the plain PyPI wheel for
#      linux-x86_64 IS the CUDA build.
#
#   2) this file:  pip install -r requirements.txt
#      It brings deepspeed, and with it ninja, packaging and psutil -- the three
#      packages the flash-attn build needs and does not install for itself. The
#      `ninja` EXECUTABLE must also be on PATH (the wheel puts it in the
#      virtualenv's bin/): DeepSpeed builds CPU-Adam just in time for
#      configs/deepspeed/zero2_offload*.json.
#
#   3) flash-attn, only after 1) and 2), with build isolation off:
#        MAX_JOBS=4 FLASH_ATTN_CUDA_ARCHS=90 \
#            pip install flash-attn==2.8.3 --no-build-isolation
#      FLASH_ATTN_CUDA_ARCHS is a ';'-separated list of compute capabilities and
#      defaults to "80;90;100;120" -- building only yours is much faster. Needs
#      nvcc on PATH or CUDA_HOME set; the installer tries a matching prebuilt
#      wheel from the project's GitHub releases before compiling. flash-attn is
#      the default attention implementation but not mandatory: pass
#      model.attn=sdpa (training) or --attn sdpa (evaluation) to run without it,
#      and the adapters fall back to sdpa on their own with no CUDA device.
#
#   4) the two Waymo pieces that are not installable from PyPI in a usable form:
#      the E2E message definitions for the decoder, generated by one command --
#        bash data_preparation/make_wod_desc.sh        # -> third_party/wod_e2e.desc
#      -- and rater_feedback_utils.py for the official score. See requirements-cpu.txt.
# ---------------------------------------------------------------------------
